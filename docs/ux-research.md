# 使用者研究：誰會用「出門前」

更新日期：2026-10-22。這份文件從軟體工程的角度推估使用者與需求，**還沒有經過真實使用者訪談或可用性測試**（PROJECT_PLAN 的 Validation Iteration 仍待執行）。下面的 persona 是可以被證偽的假設，不是調查結果。

## Persona

| Persona | 情境 | 裝置與環境 | 最在意 |
| --- | --- | --- | --- |
| **A. 跨縣市通勤／出差的上班族** | 早上出門前或在高鐵上，確認今天要去的縣市有沒有豪雨、強風特報。 | 手機為主，單手操作，可能只有行動網路。 | 5 秒內得到答案；影響範圍是山區還是平地；有效到幾點。 |
| **B. 週末出遊的規劃者** | 前一晚或出發當天早上，決定要不要去海邊、登山或改行程。 | 前一晚用桌機或平板，出發時用手機。 | 警特報種類與範圍；觀測雨量、陣風可當參考；官方原文在哪。 |
| **C. 替家人查的照顧者** | 颱風期間替南部老家的長輩確認狀況，再把連結傳到 LINE 群組。 | 手機。 | 分享出去的連結打開就是那個縣市；長輩看得懂；不會被誤導成「安全」。 |
| **D. 作品集訪客／技術審閱者** | 從使用者的個人首頁點進來，評估作者的產品判斷與工程品質。 | 桌機為主，大螢幕，常同時開 DevTools 或 GitHub。 | 第一眼的設計品質；資料可信度怎麼處理；程式、測試、文件是否紮實。 |

## 前 3 項任務

1. **確認目的地現在有沒有有效的 CWA 警特報**，以及影響範圍與有效時間（A、B、C）。
   - 完成標準：選定縣市後，不需捲動就看到結論、警特報名稱與時間。
2. **判斷這份資料能不能信**：是即時、快取，還是無法確認；資料是什麼時候取得的（全部）。
   - 完成標準：頁首燈號與答案卡的時間欄位，一眼看得出狀態；過期或失敗時不出現「沒有警報」的結論。
3. **前往官方原文或把結果分享出去**（B、C）。
   - 完成標準：一顆明確的「到 CWA 官方頁確認」按鈕；網址帶 `?county=`，貼到 LINE 打開就是同一個縣市。

次要任務：瀏覽全台哪些縣市有警特報（地圖、依種類分組的清單）；看測站觀測當參考。

## 非功能需求

| 類別 | 需求 | 目前做法與驗證 |
| --- | --- | --- |
| 可信度 | 來源失敗或資料超過 24 小時時，不得顯示「安全／無警報」 | `warningViewStateAt` 依資料時間分段；App 與 presentation 測試涵蓋邊界 |
| 時效 | 答案旁標示資料時間；頁面開著也會老化；門檻對齊實際排程 | ≤ 90 分鐘即時、≤ 6 小時稍舊、≤ 24 小時過舊，超過 24 小時不下結論 |
| 效能 | 手機 4G 下 LCP < 2.5 s、CLS < 0.1 | Lighthouse 行動版 performance 97、CLS 0.066（見 PR 說明）；不載入中文 webfont |
| 可及性 | WCAG 2.1 AA：文字對比 4.5:1、圖形 3:1、觸控目標 ≥ 44 px、鍵盤可操作 | `tests/designTokens.test.ts` 自動檢查色彩 token；Lighthouse accessibility 100 |
| 韌性 | 颱風期間流量尖峰、CWA 來源暫時失效 | GitHub Pages 靜態部署；7 天內的快照都可當備援，並標示資料時間；失敗時引導到官方頁 |
| 隱私 | 不追蹤、不需要帳號、不在瀏覽器放 API key | 沒有分析腳本；只在 localStorage 存深淺色偏好 |
| 可維護 | 改 UI 不影響資料正確性 | 資料層（`cwaClient`、`riskEngine`）與呈現層（`presentation`）分開，各有測試 |

## 裝置評估

- **整體市場：** StatCounter 2026 年 9 月台灣網頁流量，行動 58.05%、桌機 38.58%、平板 3.37%（[來源](https://gs.statcounter.com/platform-market-share/desktop-mobile-tablet/taiwan)）。
- **本站推估：** A、C 幾乎只用手機，B 兩者都用，D 以桌機為主。「出門前」的情境偏向移動中查詢，所以真實使用者的手機比例應高於市場平均，推估約 65–75%。作品集訪客則以桌機為主。以上是推估，上線後沒有流量分析可以驗證（本站刻意不放追蹤）。
- **結論：兩邊都重要，兩邊都要做好看。**
  - 手機是主要的「使用」裝置：版面以手機優先設計，答案卡在第一屏，地圖放在後面，警特報分組預設收合，觸控目標 ≥ 44 px。
  - 桌機是主要的「第一印象」裝置：答案和地圖左右並排，第一屏就看得到全台狀態與設計品質。
