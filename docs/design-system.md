# 設計語言

這份文件記錄「出門前」的設計語言，以及它參考了哪些產品。所有 token 都在程式碼裡：顏色在 `src/index.css`，字體、圓角、動效與觸控尺寸在 `tailwind.config.ts`。色彩對比由 `tests/designTokens.test.ts` 自動檢查。

## 參考了什麼

| 參考 | 我們學到的 | 落實在哪 |
| --- | --- | --- |
| Linear | 中性色為底，顏色只留給狀態；介面安靜，動效克制 | 介面幾乎全是灰藍中性色，紅、橙只出現在警特報上 |
| Vercel（Geist） | 高對比的灰階、等寬數字，大量數字也能好讀 | `.tabular` 用在時間與觀測值；`ink`、`muted` 兩級文字 |
| Stripe 的無障礙色彩系統 | 先定好對比要求再選色，不是選完再補救 | 每組文字和背景都有 4.5:1 的測試保障 |
| Apple 天氣 | 嚴重天氣的提示放在地點資訊的最上方 | 答案卡第一行就是 CWA 警特報結論，觀測放在後面 |
| Windy | 地圖是主角，圖例緊貼地圖 | 圖例和各狀態的縣市數直接放在地圖下方 |
| Observable／Plot | 少裝飾、直接標註、數字對齊 | 觀測區用格線表格，不用漸層圖示卡片 |
| Radix Colors | 顏色依用途分層：背景、邊框、實色、文字 | 每種狀態都有 `soft`（背景）、`DEFAULT`（實色）、`ink`（文字）三層 |
| shadcn/ui、Tailwind | 語意化 CSS 變數對應 Tailwind class，一套名稱同時支援深淺色 | `bg-surface`、`text-muted`、`bg-alarm-soft` 等 |
| Design tokens（W3C DTCG） | 設計決策要有名字、集中定義 | token 定義在 `:root` 與 `:root.dark`，元件只用語意名稱 |

## 色彩

| Token | 用途 | 淺色 | 深色 |
| --- | --- | --- | --- |
| `bg` / `surface` / `raised` | 頁面、面板、面板內區塊 | 灰藍底、白、淺灰 | 深海軍藍三階 |
| `ink` / `muted` | 主要文字、次要文字 | 對比 ≥ 14:1、≥ 5.5:1 | 對比 ≥ 14:1、≥ 5.5:1 |
| `accent` | 互動元素（連結、主要按鈕、即時燈號） | `#1858A0` | `#6EA8F0` |
| `alarm` | CWA「警報」（例如颱風警報） | `#C8263D` | `#F05C6C` |
| `advisory` | CWA「特報」（例如大雨、強風特報） | `#CC7A0A` | `#F2B046` |
| `calm` | 未列有效警特報：**刻意不用綠色** | 灰藍 | 灰藍 |
| `unknown` | 待確認：一定搭配斜線紋 | 淺灰加斜線 | 深灰加斜線 |
| `sea` | 地圖底色 | | |

規則：

- 狀態色只用來表達 CWA 自己的分級，不用來裝飾。
- 地圖色塊和海的對比至少 3:1（WCAG 1.4.11）。
- 「待確認」不能只靠顏色辨識，必須加斜線紋。

## 字體

- **Barlow**：自架，只含 Latin 子集，用於數字與英文。它有路標字體的氣質，切合「出門前」的語境；數字一律用等寬（tabular）。
- **中文：使用各平台系統字體**（PingFang TC、Noto Sans CJK、微軟正黑體）。不載入中文 webfont，因為一套 Noto Sans TC 動輒數 MB，會拖慢手機首屏，字體替換時還會造成版面跳動。
- **字級階梯**：只能使用 12／14／16／18／22／28／36／48／64 px，定義在 `tailwind.config.ts` 的 `fontSize`，Tailwind 的 `text-xs` 到 `text-5xl` 各對應一級。
  - 內文 16px，行高 1.75；次要說明 14px。
  - 12px 只用在時間戳、資料來源時間與腳註，全頁佔比 ≤ 15%（實測 12–14%）。
- **唯一主焦點**：首屏只放大「答案」。
  - 選了縣市時是警特報項數，例如「有 3 項警特報」；沒選時是全台列有警特報的縣市數。
  - 桌面 64px、手機 48px，用狀態色。
  - 其他首屏文字 ≤ 28px，所以主焦點至少是第二大文字的 2 倍。
  - 縣市名稱以 22px 放在答案上方；網站標語併入頁首（18px）。

## 間距與版面

- 間距只用 8pt 階梯：4／8／12／16／24／32／48／64。
- 單一容器：最大寬度 1280px，左右 gutter 為 16／24／32px（手機／平板／桌機）。
- 桌面只用一種兩欄格線（`lg:grid-cols-2 gap-8`）。所有區塊的左緣只會落在兩條線上：容器邊和第二欄邊（1440 寬時是 112 和 736）。
- 版面以平面分隔為主：區塊之間用分隔線和留白，不用一層層有內距的卡片，避免內容左緣各自內縮。
- 首屏只有一段說明文字（≤ 2 行）。免責聲明、資料來源與方法說明都放在頁尾。
- 圓角表達層級：`control` 8px（按鈕、選縣市按鈕）、`inner` 12px（區塊）、`panel` 16px（地圖底）。

## 動效

- 時長：`fast` 120 ms（hover）、預設 160 ms、`slow` 320 ms（地圖換色）。曲線統一用 `cubic-bezier(0.2, 0, 0, 1)`。
- 自動發生的動效只有一個：資料到達時地圖色塊淡入。其他動效都由使用者觸發（展開清單、按鈕回饋）。
- `prefers-reduced-motion` 開啟時停用所有動畫與平滑捲動。

## 互動與狀態

- 觸控目標至少 44 × 44 px（`min-h-touch`、`h-11`）。地圖上的小縣市低於這個尺寸，以下拉選單和「依地區選縣市」按鈕作為等效的操作方式（WCAG 2.5.8 的 equivalent 例外）。
- 每種資料狀態都有明確的呈現：
  - 載入中：中性文案，佔位高度與實際內容相近，避免版面跳動。
  - 即時：藍色燈號加相對時間。
  - 建議更新：資料超過 30 分鐘。
  - 快取：橙色，地圖加斜線。
  - 已過期或無法確認：紅色，fail closed，地圖整張改成待確認。
  - 空資料：只寫「未列」，不寫「安全」。
- 深淺色：預設跟隨系統，可手動切換並記在 localStorage。首次繪製前就套用主題，避免閃爍。
