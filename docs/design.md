# 設計筆記

這份筆記記錄「出門前」介面背後的取捨：誰會用、參考了哪些產品、用了哪套設計規則。

## 使用者與任務

這些 persona 是我對使用情境的推估，還沒有經過訪談或可用性測試。

| Persona | 情境 | 最在意 |
| --- | --- | --- |
| 跨縣市通勤、出差的上班族 | 出門前或在高鐵上，用手機確認今天要去的縣市有沒有豪雨、強風特報 | 5 秒內得到答案；影響範圍是山區還是平地；有效到幾點 |
| 週末出遊的規劃者 | 前一晚用桌機決定行程，出發時用手機再看一次 | 警特報種類與範圍；觀測雨量與陣風當參考；官方原文在哪裡 |
| 替家人查詢的人 | 颱風期間替南部的長輩確認狀況，再把連結傳到群組 | 分享的連結打開就是那個縣市；看得懂；不被誤導成「安全」 |

前三項任務：

1. 確認目的地現在有沒有有效的 CWA 警特報，以及範圍與時間。
2. 判斷這份資料能不能信：是即時資料還是快照、資料是什麼時候的。
3. 前往官方原文，或把結果分享出去（網址帶 `?county=`）。

裝置：StatCounter 2026 年 9 月台灣網頁流量為行動 58%、桌機 39%、平板 3%（[來源](https://gs.statcounter.com/platform-market-share/desktop-mobile-tablet/taiwan)）。「出門前」的情境偏向移動中查詢，所以我預期手機比例更高。兩種裝置都要好用：手機以答案優先、觸控目標至少 44px，桌機並排顯示答案、地圖與全台一覽表。

## 參考的產品

| 產品 | 借鏡的做法 |
| --- | --- |
| 日本氣象廳警報頁 | 版面結構與節奏：藍色標題列加淺藍時間帶的表格、等級色塊欄、「縣 × 災害」的全國表格。主要的版面參考 |
| tenki.jp | 官方發表時間與「現在」時間分開標示 |
| NWS | 一個區域有多項警報時，取最高等級上色 |
| MeteoAlarm | 全歐一致的等級色階；總覽、地區、詳情三層下鑽 |
| Windy、Zoom Earth、Ventusky | 圖例貼近地圖；服務中斷時主動告知；標示資料更新時間 |
| 中央氣象署警特報頁 | 地圖與清單並列、同類警特報集中說明 |

不採用：動態氣象場、圖磚底圖、合成的風險分數。這些與「確認官方警特報」的任務無關，還會模糊官方資料與本站整理的界線。

地圖幾何來自 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（MIT，源自內政部縣市界線開放資料），建置時以 `scripts/build-county-map.ts` 簡化並預先投影成 SVG path（約 30 KiB），不需要地圖函式庫或圖磚。

## 版面

- 內容靠左，左右 gutter 40px（手機 20px）；清單欄最寬 1043px，右側地圖欄 320px。
- 每個區塊都是表格式結構：實色標題列、淺藍時間帶、1px 格線，沒有圓角。
- 導覽列是實色藍底，項目之間用直線分隔；縣市選單放在麵包屑的第二個分頁。
- 首屏只有一個焦點：答案（「有 3 項警特報」）。桌面 64px、手機 48px，用狀態色；其他首屏文字不超過 22px。

## 字體與間距

- 系統字體加中文 fallback，不載入網頁字體。
- 字級階梯只有 12／14／16／18／22／28／36／48／64px。內文 16px；12px 只用於時間戳與腳註，全頁占比約 6%。
- 間距用 4／8／12／16／24／32／48／64px。

## 色彩

| 用途 | 說明 |
| --- | --- |
| `--brand` 藍 | 導覽列與表格標題列 |
| `--alarm` 紅 | CWA「警報」 |
| `--advisory` 橙 | CWA「特報」 |
| `--none` 灰 | 未列有效警特報；刻意不用綠色，因為「未列」不等於安全 |
| `--mark` 橙紅 | 品牌標記，兩個主題相同 |

- 顏色只表達 CWA 自己的分級，不是本站的風險分數。
- 「待確認」一定加斜線紋，不單靠顏色辨識。
- 文字對比至少 4.5:1、地圖色塊對比至少 3:1，由 `tests/designTokens.test.ts` 在淺色與深色主題下自動檢查。
- 預設淺色，另有深色主題；可手動切換，偏好存在 localStorage。

## 資料狀態

資料年齡由瀏覽器依資料本身的時間計算。年齡只改變標示，不改變答案：

| 資料時間 | 畫面 |
| --- | --- |
| ≤ 90 分鐘 | 即時，中性色標示「資料時間 HH:MM · N 分鐘前」 |
| ≤ 6 小時 | 答案與地圖不變，時間標示改為琥珀色 |
| ≤ 24 小時 | 同上，加註更新頻率並附官方連結 |
| 超過 24 小時 | 仍顯示最後一筆資料，但答案改為「無法確認」、地圖加斜線 |
| 取不到任何資料 | 錯誤卡片；頁首與說明仍在 |

每項警特報會在當下時間重新套用它自己的有效期間，已到期的會移除並註明數量。

## Icon 與品牌標記

- Icon 一律使用 [Lucide](https://lucide.dev/)（ISC）：24px 格線、stroke 1.75、圓角線端、不填色；按鈕內 20px，其他 16px。
- 品牌標記是橙紅圓角方形（圓角為邊長的 22%），中間一個白色 Lucide `cloud-lightning`（邊長的 58%、stroke 2）。`public/brand/mark.svg` 是來源，favicon 與 apple-touch-icon 都由它產生。

## 動效

- 時長 120／160／320ms，曲線 `cubic-bezier(0.2, 0, 0, 1)`。
- 自動發生的動效只有資料到達時地圖色塊的淡入；使用者設定 `prefers-reduced-motion` 時全部停用。

## 效能

用 Lighthouse 量本機 production build（`?county=臺北市`）：accessibility 100；performance 在快照為最新時約 99–100，快照過舊時答案要等即時資料，手機約 67。改善方向是讓警特報先到先顯示，不等約 3 MB 的觀測資料。
